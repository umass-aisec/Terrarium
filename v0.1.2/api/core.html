Logging¶

class terrarium.core.logger.AgentTrajectoryLogger(environment_name='Unknown', seed=0, config=None, run_timestamp=None, log_dir=None)[source]¶

Bases: object

Logger for capturing agent reasoning and tool call trajectories.

Logs the internal decision-making process of agents including: - Reasoning text (from response.output_text) - Tool calls with parameters - Organized by agent → iteration → phase → trajectory steps

Initialize the agent trajectory logger.

Parameters:

  • environment_name (str) – Name of the environment (e.g., “Hospital”, “SmartGrid”)

  • seed (int) – Simulation seed for unique log files

  • config (Dict[str, Any]) – Full configuration dictionary containing all simulation settings

  • run_timestamp (str | None)

  • log_dir (Path | None)

log_trajectory(agent_name, iteration, phase, trajectory_dict, round_num=None)[source]¶

Log a trajectory for an agent during a specific iteration and phase.

Parameters:

  • agent_name (str) – Name of the agent

  • iteration (int) – Current iteration number

  • phase (str) – Current phase (planning, execution)

  • trajectory_dict (Dict[str, Any]) – Dictionary of trajectory steps with keys like “step_1”, “step_2” Each step contains: - tools: List of tool calls formatted as “{tool_name} – {parameters}” - reasoning: Reasoning text (from response.output_text)

  • round_num (int | None) – Round number (for planning phase only, None for execution)

Return type:

None

class terrarium.core.logger.BlackboardLogger(config, run_timestamp=None)[source]¶

Bases: object

Logger specifically for tracking the complete blackboard state.

Saves the entire blackboard after each agent interaction, providing a complete view of all agent communications and their evolution. Now supports multiple blackboards with separate log files.

Initialize the blackboard logger.

Parameters:

  • config (Dict[str, Any]) – Full configuration dictionary containing all simulation settings

  • run_timestamp (str | None) – Optional run timestamp override for log directory naming
