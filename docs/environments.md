# Environments

Terrarium includes several example environments for decentralized multi-agent experiments.

## Meeting Scheduling

Calendar agents assign meetings while satisfying constraints and preferences across multiple schedules.

## Personal Assistant

Assistant agents choose outfits for a human while balancing social norms, personal preferences, and constrained item selection.

## Smart Grid

Home agents schedule appliance usage throughout the day while avoiding overloads on the power grid.

## Hospital

Hospital agents coordinate task decisions in a healthcare-inspired setting.

## Jira Ticket

Jira ticket agents coordinate over issue status and assignment workflows.

## Creating New Environments

New environments should provide:

- State initialization.
- Tool definitions.
- Tool execution handlers.
- Evaluation or scoring logic.
- Prompt text for the agents.
